# 🌍 Carbon Footprint Simulator

A Windows-based desktop application developed in C# that calculates and simulates carbon footprints. This project was built to practically implement core **Object-Oriented Programming (OOP)** principles, utilizing modular class structures, encapsulation, and clean UI design.

## 🚀 Key Features
* **Interactive Dashboard:** A user-friendly Windows Forms interface to input data and view footprint results.
* **OOP Architecture:** Built entirely using Object-Oriented principles for clean, maintainable, and modular code.
* **Real-time Calculation:** Instantly calculates carbon emissions based on user inputs.
* **Encapsulation & Security:** Secure data handling using C# classes, properties, and access modifiers.

## 🛠️ Tech Stack & Tools
* **Programming Language:** C#
* **Framework:** .NET (Windows Forms)
* **Core Concepts:** Object-Oriented Programming (OOP), File Handling
* **IDE:** Microsoft Visual Studio
